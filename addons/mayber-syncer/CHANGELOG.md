# Changelog

All notable changes to the Maybe App Importer addon are documented here.

## [1.0.0] - 2026-05-02

### Added

- Initial Maybe-compatible account and transaction importer.
- Secure settings for API base URL and API key.
- Direct Maybe API requests for hosts that allow Wealthfolio CORS preflights.
- Account-name matching with automatic missing cash-account creation.
- Transaction pagination, duplicate detection, Wealthfolio import validation,
  and import execution.
